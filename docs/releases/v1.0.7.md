# NestSpace v1.0.7

这个版本加入完整的 Java 插件平台与插件中心，统一 AI 助手异步任务流程，并重构容器兼容运行时。多实例隔离、应用启动、插件扩展、进程调度和 Android 15–17 兼容性得到集中增强。

## 重点更新

- 新增 Java 插件平台和桌面「插件中心」。插件可以扩展 AI 助手、工具结果界面、设置页、模型服务和目标应用的运行时兼容策略。
- AI 助手操作应用、浏览器导航和下载统一进入异步任务流程，可查看状态、速度与剩余时间，并支持等待、取消以及后台、镜像、可见三种显示模式。
- 支持 Debug 源码插件直接开发，也支持安装 `.nest` 插件包；插件可以从插件中心或远程 MCP 管理。
- 重构容器运行时，统一处理实例身份、存储、账号、系统服务、WebView、Provider、多进程和 native 环境，提高复杂应用的启动成功率。
- 同一应用的每个实例现在可以独立显示在桌面和应用管理中，并提供实例信息查看与单实例数据清理。

## 新增

- 新增插件中心，支持插件搜索、分类、详情、内置插件启用/停用、参数设置、重命名、分享、导出、删除和从文件安装。
- 新增 Java-first 插件 SDK，支持 Agent 提示词、问答、模型请求 Hook、Agent Tool、工具调用 Hook、自定义工具 View、命令和后台任务。
- 插件可以接入 Keystore 加密密钥、私有存储、缓存、SQLite、通知、文件选择与导出、分享、剪贴板、HTTP、SSE 和 WebSocket。
- 新增插件 LLM Provider，可通过 `plugin://` 地址接入自定义模型服务，并使用统一的请求入口按模型配置选择流式或完整响应。
- 新增插件语音 Provider，插件可以合成文字音频，由宿主统一负责播放、队列、停止和音频焦点；Agent 和 MCP 可使用 `speech_speak`、`speech_stop` 和 `speech_status`。
- 新增稳定的运行时代理 API，插件可以按目标包名和 `versionCode` 贡献兼容 Profile、Application/Activity 生命周期 Hook 和 APK 类名索引。
- 运行策略支持继续使用容器、回退到宿主应用或阻止启动；版本匹配支持精确值、通配符、前缀和区间。
- MCP 新增 `plugin_list` 和 `plugin_manage`，可列出、安装、卸载、重命名、配置插件，启停内置插件并调用插件命令。
- AI 助手新增统一的异步任务能力，应用操作、浏览器任务和下载可以通过状态、等待和取消接口管理，等待超时不会再被误判为成功。
- 界面检查统一使用节点优先的 `ui_observe`，默认返回文本、描述、边界和可交互状态；只有节点不足或画面属于视频、游戏、Canvas 等视觉内容时才附加截图。
- AI 助手支持后台、镜像和可见三种应用显示模式；需要登录、验证码或用户亲自操作时，可以把当前应用交还用户。
- 应用管理现在逐个显示实例，新增实例详情页，可查看实例 ID、创建时间、最近启动、环境版本、兼容配置、最近探测和存储目录。
- 支持单独清空某个实例的数据，不影响同一应用的其他实例。
- 容器新增实例级存储、AccountManager、Android ID、权限、WebView 数据目录和进程身份隔离。
- 新增 APK/实例运行时诊断与真实启动阶段展示，启动页会显示 ClassLoader、Application、Provider 和首个 Activity 等启动阶段。
- 新增多进程组件支持，覆盖显式 Activity、Service、Provider、广播、WebView 和插件 APK 中的组件。
- 扩展 native 环境兼容，支持目标路径、`/proc`、系统属性和基础 native 库加载，并加强 16 KB 页面大小设备的兼容性。
- 将 Android 15、16、17 及带 ARM 转译的 MuMu 模拟器纳入验证范围。

## 修复

- 修复语音悬浮球在多个容器进程中重复创建，出现多个话筒入口的问题。
- 修复 AI 助手页面在旋转屏幕后丢失当前标签页状态的问题。
- 修复同一容器第二次打开应用时可能因宿主与目标资源身份切换而崩溃的问题。
- 修复 Activity alias、启动入口和 Intent 解析不正确，导致免责声明、首页或指定 Activity 无法正常打开的问题。
- 修复部分应用的 `0` 优先级 Provider 没有按正常 Android 启动顺序初始化，导致首页或 SDK 初始化失败的问题。
- 修复目标生命周期回调重复执行，可能造成视图层级循环或异常崩溃的问题。
- 修复槽位回收失败后容器启动卡住的问题；无法及时退出的旧进程会被再次终止，并改用其他可用槽位。
- 修复目标主线程致命异常后留下半初始化容器、继续拖慢宿主的问题；现在会记录崩溃并只重启对应槽位。
- 修复已禁用的 Activity 或 alias 仍被识别为启动入口的问题。
- 修复部分内容应用首次进入视频、频道或 Tab 页面时出现 `Fragment already added`、黑屏或页面无法显示的问题。
- 修复多个实例共用权限、Android ID、账号或 WebView 数据目录，导致数据串用和初始化异常的问题。
- 修复镜像模式下执行点击、输入或搜索后，助手控制的应用被意外切换成全屏的问题；本地助手现在默认保持在镜像模式，只有显式选择可见模式或交还用户时才打开前台窗口。
- 修复工具步骤完成后镜像窗口过早自动关闭，导致后续连续操作中断的问题；现在会等整项任务结束后再保留 10 秒，期间继续操作会重新计时。
- 修复网页中的部分链接和跳转仍可能绕过内置浏览器、交给系统浏览器打开的问题。
- 修复虚拟应用无法正确获取系统语言和地区，导致界面语言、日期或地区相关内容不符合设备设置的问题。

## 优化

- 宿主把悬浮球、MCP、任务恢复、模型预加载等非首屏工作延后到首帧之后，减少主进程启动竞争。
- 容器启动页改为跟随真实初始化阶段更新，不再依赖固定等待时间估算进度。
- 异步任务和浏览器下载会显示实时速度、进度与预计剩余时间，并支持在任务中心查看状态和主动取消；同一助手会话的新下载会清理旧连接。
- AI 助手改为优先读取界面节点，减少不必要的截图、图片传输和等待时间；新增观察结果中的节点数量和截图建议，帮助模型只在必要时补图。
- 优化进程池回收策略：自动模式根据可用内存调整槽位上限，固定模式严格使用用户设置的 1–16 个槽位，并优先回收最久未使用的后台容器。
- 优化进程槽位复用：复用前仍会结束旧进程，避免不同应用的同名 native 库和 JNI 全局状态互相污染，同时减少锁等待和重复进程扫描。
- 缓存 APK 元数据和启动索引，减少每次启动时重复解析 APK、Manifest 和 native ABI。
- 缓存目标 WebView User-Agent，并在容器启动期间提前准备，降低 WebView 初始化对首屏的影响。
- 整理运行时模块边界，将运行时核心、兼容层和共享契约收进应用模块，同时保留独立的 Java 插件 API，并将目标专用兼容逻辑隔离到插件或版本化 Profile。
- 插件能力改用 Agent、运行时、自动化、存储、网络等分组权限展示和校验，旧细粒度权限继续兼容；停用插件后会立即移除对应 Hook、工具、Provider 和运行时代理。
- 未配置模型时新增明确的未连接图标和配置入口；离线语音模型下载补充线路选择、实时速度和剩余时间。
- 新增插件 API、运行时、存储、网络、SSE、WebSocket、Provider、多进程和 native 环境测试。
- 更新插件编写指南、运行时模块说明、MCP 工具参考、构建文档和多语言站点。

## 升级注意

- NestSpace 是实验性项目，主要用于验证 AI 能力，不保证所安装 App 的兼容性和安全性。
- 使用相同正式签名从 `v1.0.6` 覆盖安装时，已有空间和应用数据会保留。Debug APK 与正式 APK 签名不同，切换前需要先卸载。
- 实例数据格式会自动升级。首次启动新版本时可能进行元数据迁移，请勿在迁移过程中强制结束应用。
- 插件安装包统一使用 `.nest` 扩展名；分享、导出和从文件安装均使用该格式。
- `.nest` 安装器和插件 SDK 仍属于持续改进中，未来可能会发生变化。
