# 设置详解

桌面「空间设置」采用两级分类：首页保留常用入口，第二层按应用、AI 助手和系统网络分类，低频功能继续放在第三层。

## 首页常用

| 入口 | 用途 |
| --- | --- |
| 应用管理 | 导入宿主应用、导入 APK、启动、多开和卸载 |
| 模型设置 | 配置 Claude / OpenAI 兼容接口和模型参数 |
| 权限级别 | 设置敏感操作是否需要确认 |
| MCP 控制服务 | 启动对外的 MCP Server、查看 Token 和连接地址 |
| 悬浮球 | 语音助手快捷入口、颜色、透明度和离线语音模型 |
| 外观 | 壁纸和容器顶部提示 |

首页下方还有「应用与容器」「AI 助手」「系统与网络」三个分类入口，以及独立的「关于」页面。

## 插件中心

插件中心不是“空间设置”的二级页面。它作为桌面独立应用入口打开，返回时直接回到桌面。
插件中心统一管理已安装的源码插件和第三方插件，系统内置能力不会作为列表项显示。

长按插件图标可以设置、重命名、分享或导出；第三方 `.nest` 还可以删除。插件设置
页由宿主根据插件声明的设置 Schema 统一渲染，字段、校验和持久化由宿主负责。

详见 [插件平台与 Java SDK](plugin-center.md) 和 [插件编写指南](plugin-authoring.md)。

## 应用与容器

### 应用管理

安装 APK、导入宿主已安装的应用、管理实例和容器。详见 [应用安装与管理](app-manager.md)。

### 容器槽位

容器进程池最多有 16 个槽位，每个槽位对应一个独立容器进程。

- **动态管理**（默认）：按内存动态使用槽位，内存紧张时优先关闭最久未使用的后台容器。
- **固定上限**：限制为 1–16 个槽位。

降低上限会立即结束超出范围的容器进程，不会删除应用数据。

### 坐标模拟

为虚拟应用模拟经纬度：

- 打开开关后，虚拟应用通过 `LocationManager` 读取到设定位置；
- 只影响虚拟应用，不修改真实设备定位，也不需要 Root；
- 应用仍需获得定位权限；
- 自有地图 SDK 或 Play 服务定位可能仍使用真实位置。

## 容器高级

入口：**空间设置 → 应用与容器 → 容器高级**。

### 宿主控制（Root）

需要真实设备已经 Root，并允许 NestSpace 使用 `su`。

- 开启后，AI 助手和远程 MCP 会获得 `host_*` 工具；
- 可以观察、点击、输入、截图和启动真实设备应用；
- 系统浏览器不会通过 `host_launch` 或系统空间 `space_launch` 打开；
- 关闭后，宿主工具立即从工具列表中移除；
- 权限很高，只应在可信设备上使用。

### 容器自检

检查启动、界面读取、截图、独立进程、WebView 和 MCP 等基础能力。结果分为通过、部分通过、失败和跳过，可复制完整报告。

## AI 助手

### 模型设置

支持 Claude 兼容和 OpenAI 兼容接口，可以保存多个模型配置并随时切换。首次没有配置时，AI 助手会显示未连接状态和「去配置大模型」入口；配置完成前不会执行命令或工具调用。

每个配置包含：

- 名称；
- 协议；
- Base URL；
- API Key；
- 模型；
- 最大上下文 tokens；
- 最大输出 tokens；
- Temperature；
- 最大工具轮次；
- 思考程度；
- 流式输出开关。

模型编辑页还提供：

- Telegram / 第三方兼容接口的常用预设；
- API Key 明文查看按钮；
- Anthropic 接口缺少版本路径时自动补 `/v1/messages`；
- 「测试连接」真实请求；
- 连接成功、失败、保存和删除结果使用 Toast 提示。

API Key 使用 Android Keystore 加密保存。详见 [AI 助手](assistant.md)。

### 系统提示词

所有模型共用一份系统提示词。运行时 NestSpace 还会追加当前时间、记忆、技能索引、工具规则和显示模式规则。

### 权限级别

| 级别 | 行为 |
| --- | --- |
| 严格 | 安装/卸载、权限变更、风险点击、下载等都需要确认 |
| 标准 | 增加安装/卸载确认；记忆和自动起草的技能直接保存 |
| 宽松 | 只有支付、下单、转账、红包等金钱操作提示 |
| 自定义 | 自己选择需要确认的类别 |

自动起草的技能始终默认停用，需要手动启用。

### 悬浮球

- 打开或关闭悬浮球；
- 设置宿主界面和容器内颜色；
- 调整透明度和位置；
- 选择中文或英文语音模型；
- 选择离线语音模型下载线路；
- 下载、删除或切换语音模型。

悬浮球和语音对话界面只在 AI 助手前台可见；离开 AI 助手或容器进入后台后会自动隐藏。

### 高级助手工具

入口：**空间设置 → AI 助手 → 高级助手工具**。

- **MCP 工具**：配置外部 MCP Server，为本地助手增加工具；
- **记忆与技能**：查看、批准、置顶、编辑和删除记忆与技能；
- **定时任务**：单次、每天、每周和固定间隔任务；
- **评测与回放**：用真实任务测试 Agent，并重放成功流程；
- **子任务记录**：查看子 Agent 状态、结果和停止操作；
- **Token 统计**：查看每次请求的输入、输出和思考 token；
- **MCP 控制服务**：NestSpace 对外提供的控制服务。

## 系统与网络

### 外观

- 选择、更换或清除桌面壁纸；
- 设置容器顶部提示；
- 壁纸保存在应用内部，卸载 NestSpace 时一并删除。

### 语言

支持跟随系统、中文和 English，修改后界面立即刷新。

### 浏览器代理

为内置浏览器配置 HTTP 或 SOCKS 代理：

- 所有标签页和下载共用；
- 支持逗号分隔的绕过规则；
- 需要 Android 10+ 且 WebView 支持 `PROXY_OVERRIDE`；
- 暂不支持用户名/密码认证。

详见 [内置浏览器](browser.md)。

## 关于

“关于”页面位于设置首页底部，包含：

- Telegram 交流群；
- 交流群二维码和「保存二维码」按钮；
- 当前版本号和应用介绍。

Android 10 及以上会把二维码保存到相册的 `Pictures/NestSpace`；旧系统保存到应用图片目录。
