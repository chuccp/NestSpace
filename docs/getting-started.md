# 快速开始

本文从零开始走一遍：安装 NestSpace、导入第一个应用、启动、多开和使用 AI 助手。整个过程不需要 root，也不需要开启无障碍服务；手机上的基本操作不需要电脑和 adb。

## 1. 确认系统版本

- Android 7.0（API 24）及以上；
- Android 7.1、15、16、17 已验证；
- 如果目标应用只包含 arm64 原生库，需要 arm64 真机或带 ARM 转译的 MuMu。普通 x86_64 模拟器可能返回 `ABI_MISMATCH`。

## 2. 安装 NestSpace

从 [Releases](https://github.com/chuccp/NestSpace/releases/latest) 下载对应设备的 APK：

- `NestSpace-vX.Y.Z-arm64.apk`：ARM64 真机、MuMu 等带 ARM 转译的模拟器；
- `NestSpace-vX.Y.Z-x86_64.apk`：x86_64 PC / 没有 ARM 转译的模拟器；
- `NestSpace-vX.Y.Z-universal.apk`：全部 ABI，适合不确定架构或 32 位设备。

也可以按 [从源码构建](building.md) 自行打包。

首次打开会显示 NestSpace 桌面。桌面底部固定入口：

- **浏览器**：内置多标签浏览器；
- **AI助手**：本地 AI 助手；
- **空间设置**：应用、模型和系统配置；
- **运行管理**：查看和结束容器进程。

底部 Dock 之外，桌面应用区域还有「插件中心」入口。它像独立应用一样打开，返回后直接
回到桌面，用来管理源码插件和第三方 `.nest`。

![NestSpace 桌面](screenshots/desktop.jpg)

## 3. 导入宿主已经安装的应用

NestSpace 会把宿主应用的 APK 安装到虚拟空间，而不是创建系统应用快捷方式。

1. 打开「空间设置 → 应用管理」；
2. 点「导入应用」；
3. 勾选设备上已经安装的应用；
4. 点「导入」，等待安装完成。

导入后：

- 应用会出现在应用管理和桌面；
- 首次启动时创建独立的「实例 1」；
- 不会复制宿主应用的账号、私有数据或登录状态；
- 同名应用已经导入时，会提示将覆盖现有版本；
- Gmail 等系统级应用能否运行，取决于它的系统服务和原生库依赖。

## 4. 导入 APK

1. 把 APK 放到手机可访问的位置；
2. 点「空间设置 → 应用管理 → 导入 APK」；
3. 在文件选择器里选中 APK；
4. 等待解析和安装。

普通应用选择一个 APK。split 应用需要一次选中 `base.apk` 和全部 split：

```text
base.apk
split_config.arm64_v8a.apk
split_config.xxhdpi.apk
...
```

导入时会检查包名、签名一致性、最低系统版本、`REQUIRE_SECURE_ENV` 和 ABI。

## 5. 启动与多开

进入「空间设置 → 应用管理」：

- 点实例按钮启动指定实例；
- 点「启动」打开最近选择的实例；
- 点「多开」创建新实例并启动。

![应用管理与多开](screenshots/app-manager.jpg)

每个实例都有独立的文件、缓存、数据库、SharedPreferences 和 native 库目录，可以同时登录同一应用的两个账号。

## 6. 整理桌面

- 长按应用：打开、应用快捷方式、排序、应用信息和卸载；
- 长按空白处：新建文件夹、模型设置、权限级别等快捷入口；
- 拖动应用：调整顺序、创建文件夹或移入已有文件夹；
- 文件夹：打开、重命名、添加应用、移出应用和解散；
- 壁纸：「空间设置 → 外观」；
- 桌面布局会自动保存。

## 7. 配置和使用 AI 助手

点桌面「AI助手」。没有模型时会显示未连接状态和「去配置大模型」入口；配置完成前不会执行命令或工具调用。

推荐进入「空间设置 → 模型设置」配置 Claude 兼容或 OpenAI 兼容接口。模型页支持第三方预设、API Key 明文查看、最大上下文、最大输出、Temperature、最大工具轮次和思考程度。连接成功或失败都通过 Toast 提示。

AI 助手的应用显示规则：

- 本地助手启动和操作虚拟应用时默认使用方形镜像小窗；
- `display_mode=background` 不显示应用或小窗，`display_mode=visible` 才正常打开前台应用；
- 登录、验证码、付款或授权等需要用户处理的步骤，使用 `hand_to_user` 把当前应用交给用户。

助手固定在「虚拟空间 1」中工作，桌面对话和悬浮语音助手共享同一份历史。

## 8. 卸载应用

两种方式：

- 长按桌面应用 →「卸载」；
- 「空间设置 → 应用管理」→ 应用行「卸载」。

卸载会删除该应用的所有实例、APK 和实例数据，无法恢复。

## 9. 数据保存在哪里

```text
/data/user/0/com.coke.nestspace/files/vspace/
  apps/                      安装的 APK
  data/<package>/<instance>/ 实例数据
```

普通用户不需要访问这些目录。卸载 NestSpace 会一并清除虚拟应用和实例数据。
