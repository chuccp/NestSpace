# AI 助手

AI 助手可以观察和操作虚拟空间里的应用、使用内置浏览器、读取页面、下载文件，并通过 MCP 接管电脑或控制真实设备。默认操作范围是「虚拟空间 1」。

![AI 助手](screenshots/assistant.jpg)

## 打开助手

- 桌面底部「AI助手」；
- 开启悬浮球后，点悬浮球圆点打开语音助手。

桌面助手和悬浮语音助手共享同一份对话历史，可以连续追问。

## 没有配置模型时

首次进入会显示未连接图标和「去配置大模型」入口。配置完成前不会执行规则命令或工具调用；
点击按钮进入模型设置并保存一个可用配置后，才可以开始任务。

## 配置模型

入口：**空间设置 → 模型设置**。

可以保存多个配置并切换。每个配置包含：

| 字段 | 说明 |
| --- | --- |
| 名称 | 配置显示名称 |
| 协议 | Claude 兼容 / OpenAI 兼容 |
| Base URL | 完整接口地址 |
| API Key | 使用 Android Keystore 加密保存，可通过眼睛按钮查看明文 |
| 模型 | 接口要求的模型名称 |
| 最大上下文 tokens | 默认 800000，最低 100000 |
| 最大输出（不含思考） | 可见回答预算 |
| Temperature | 0–2 |
| 最大工具轮次 | 默认 128，最大 1000 |
| 思考程度 | 快速 / 轻量 / 标准 / 深度 |
| 流式输出 | 默认开启；关闭后等待完整回答再显示 |

模型页提供常见第三方兼容接口预设，选择后会自动填入 Base URL 和模型。Claude 兼容接口缺少版本路径时，测试或保存会自动补 `/v1/messages`；已有 `v*/messages` 路径不会重复追加。

插件模型 Provider 使用 `plugin://<provider-id>` 作为 Base URL，模型字段填写插件
`getModels()` 返回的模型 ID。插件自己持有上游凭据，因此普通 API Key 字段可以留空。
「流式输出」开关会一并传给插件。

点「测试连接」会发起真实请求。连接成功、失败、配置保存和删除结果都通过 Toast 提示，不再占用页面顶部。

## 应用显示模式

本地 AI 发起的应用打开、浏览、搜索、点击和发布默认都在无头模式运行。助手页可以显示
一个方形镜像小窗；需要用户登录、验证码或亲自操作时，通过 `hand_to_user` 把当前应用交
给用户。任务结束 10 秒内没有继续操作时，小窗和对应应用会一起关闭。

MCP 调用可以通过 `display_mode` 选择：

- `background`：纯无头，不显示应用和小窗；
- `mirror`：无头运行并显示小窗；
- `visible`：正常打开应用。

同一时间只保留一个受管小窗；新小窗任务会关闭上一个应用及其子进程。

## 对话界面

- 默认使用流式输出，也可以在模型配置中关闭；
- 工具调用显示为可展开卡片，包含状态、参数和结果；
- 支持 Markdown、代码块、复制和文本选择；
- 浏览器下载会在对话流中显示进度；
- 「历史」入口打开运行历史列表，可以恢复或删除历史记录；
- 可以从历史记录继续之前的任务。

![助手执行多步任务](screenshots/assistant-task.jpg)

## 思考程度

对话界面可以切换思考程度，并按模型分别保存：

| 档位 | 行为 |
| --- | --- |
| 快速 | 直接回答，尽量少做额外推理 |
| 轻量 | 先做简短判断再执行 |
| 标准 | 平衡速度和质量，默认 |
| 深度 | 充分拆解和验证，适合复杂任务 |

支持原生推理参数的模型会收到 `thinking.budget_tokens` 或 `reasoning_effort`；其他兼容端点使用提示词约束。

## 工具范围

助手可以使用：

- `space_*`：列出、安装、启动、多开、停止和卸载虚拟应用；
- `ui_*`：观察 View 树、点击、输入、等待、截图和返回；
- `browser_*`：打开标签、读取、点击、下载、上传和转人工；
- `task_wait`：等待内部任务生命周期变化、终态或超时；
- `poll_tool`：只用于 UI 文本或外部服务等没有内部事件源的观察；
- `spawn_agent`：只读子任务；
- `schedule_task`：定时任务；
- 宿主控制开启后的 `host_*`；
- 用户配置的外部 `mcp_*` 工具。

内部异步任务使用 `task_wait`；等待超时不是成功，也不取消任务。等待 UI 文本时仍可用
`poll_tool` 观察 `ui_observe`。
`ui_wait_for` 仅保留为旧调用兼容入口。
所有界面观察统一使用 `ui_observe`：节点中的 id、文本、描述、边界和
clickable/scrollable 状态比截图更稳定。只有节点为空或明显不完整，或 Canvas、游戏、
Flutter、Unity、视频、图片、颜色和遮挡等视觉状态无法由节点表达时，才在同一个调用中传
`include_screenshot=true` 补充截图。第一次观察必须只看节点；结果中
`screenshot_recommended=true` 时再补图。界面检查只有 `ui_observe` 一条路径。
工具只报告速度、剩余时间和空闲状态；是否因速度慢而换节点由模型判断，确定后调用
`task_cancel`。一旦启动同助手的替代下载，运行时会强制停止旧连接。

## 内置浏览器规则

网页任务必须使用 `browser_*`：

- HTTP/HTTPS 链接留在自带浏览器；
- `target=_blank`、`window.open` 和下载页弹窗被接管；
- `intent://` 网页回退地址转成内部标签；
- 不会通过 `host_launch` 或系统空间 `space_launch` 启动系统浏览器；
- HTML、XHTML、SVG 下载文件也在自带浏览器中打开。

详见 [内置浏览器](browser.md)。

## 权限确认

入口：**空间设置 → 权限级别**。

| 级别 | 行为 |
| --- | --- |
| 严格 | 安装、卸载、权限变更、风险点击、下载等都需要确认 |
| 标准 | 增加安装/卸载确认；记忆和技能直接保存，技能默认停用 |
| 宽松 | 只有支付、下单、转账、红包等金钱操作提示 |
| 自定义 | 自己选择需要确认的类别 |

远程 MCP 客户端不受此设置影响。

## 记忆与技能

入口：**空间设置 → AI 助手 → 高级助手工具 → 记忆与技能**。

### 记忆

- 每轮对话后自动整理事实、偏好和可复用做法；
- 可以批准、置顶、编辑和删除；
- 密码、验证码、银行卡和身份证信息不会被自动记录；
- 使用时相关条目会随系统提示词发送给当前模型服务。

### 技能

- 内置技能覆盖信息调研、消息与邮件、内容整理、下载上传、设置指引、定时任务和写技能；
- 成功的多步骤任务可以自动起草技能；
- 自动起草的技能默认停用；
- 最近 3 次中失败 2 次会自动停用；
- 自定义技能支持导入 `SKILL.md`、版本历史和恢复。

## 定时任务

入口：**空间设置 → AI 助手 → 高级助手工具 → 定时任务**。

支持单次、每天、每周和固定间隔。任务到点后在原对话里执行，并发送结果通知。

## 语音助手

### 开启悬浮球

入口：**空间设置 → 悬浮球**。

1. 打开「显示悬浮球」；
2. 授予「显示在其他应用上层」权限；
3. 设置宿主界面和容器内颜色、透明度和位置。

悬浮球和语音对话界面只在 AI 助手前台可见。离开 AI 助手或容器进入后台时，会自动隐藏，不会变成系统 PiP 或后台悬浮窗。

### 使用

1. 点悬浮球圆点打开底部语音助手；
2. 点麦克风或圆点开始/停止聆听；
3. 实时显示识别结果，最终自动发送；
4. 回复后自动恢复聆听，可继续追问。

语音助手采用简化的功能快捷界面，不展示完整历史列表。需要查看历史时使用完整 AI 助手页。

### 中文空格

本地 Vosk 识别中文时可能输出逐字空格。NestSpace 会在部分和最终结果中自动整理：

```text
打 开 目 标 应 用
→ 打开目标应用
```

英文单词之间的正常空格会保留。

### 离线语音模型

- Vosk 本地识别，音频不离开设备；
- 支持中文和 English 小模型；
- 可选择和切换模型下载线路；
- 下载前会测试多个线路，每个线路测试 3 次并取最大值选择最优线路；
- 下载中断会自动切换来源；
- 模型加载后会在进程内缓存，下次打开更快。

## 子 Agent

`spawn_agent` 可以运行一个只读子任务：

- 默认 15 步，最多 40 步；
- 可以观察容器和网页，不能点击、输入或安装应用；
- 结果按不可信数据返回给主 Agent；
- 在「高级助手工具 → 子任务记录」查看和停止。

## 插件扩展

插件可以扩展 Agent 的提示词、模型前问答、模型请求、工具和工具结果展示。插件工具与其
外部 MCP 工具共用权限等级和确认流程；工具结果页可以由插件返回任意 Android View。

插件设置不在“空间设置”中，而是在桌面打开插件中心后长按插件图标进入。插件被删除或
停用后，新对话不再使用它的 Hook。插件开发和调试见
[插件编写指南](plugin-authoring.md)。

## 常见问题

### 测试连接失败

- 检查 Base URL、API Key 和模型名称；
- Claude 兼容地址会自动补 `/v1/messages`；
- 检查接口是否支持所选模型和思考参数；
- 连接失败以 Toast 显示，不再出现在页面顶部。

### 助手不操作目标应用

- 确认应用已安装到「虚拟空间 1」；
- 确认模型配置有效；
- 查看对话中的工具卡片；
- 复杂任务可以提高最大工具轮次。

### 语音识别没有反应

- 授予录音权限；
- 确认离线模型已下载完成；
- 在「空间设置 → 悬浮球」切换语言或下载线路；
- 切换到键盘输入验证其他功能是否正常。
