# NestSpace ユーザーマニュアル

> Android 上でアプリレベルの仮想スペースを実行する実験的なオープンソースプロジェクトです。

[クイックスタート](getting-started.md) · [アプリのインストールと管理](app-manager.md) · [よくある質問](troubleshooting.md) · [GitHub](https://github.com/chuccp/NestSpace)

![NestSpace デスクトップ](screenshots/desktop.jpg)

## NestSpace を選ぶ理由

- **アクセシビリティサービスを有効にする必要がない**：画面の観察、タップ、入力はアプリ内部のチャネルで直接行います。
- **adb が不要**：APK のインストール、複製（マルチインスタンス）、デスクトップの整理、AI アシスタントの利用まで、すべてスマートフォン上で完結します。
- **root が不要**：通常のアプリと同じようにインストールするだけで使え、システムを変更しません。
- **Android バージョンの要件が緩い**：Android 7.0（API 24）以降に対応し、7.1、15、16、17 で動作確認済みです。

## まず知っておくべき制限

- **NestSpace は主に AI 機能の検証を目的としています**：汎用の互換コンテナではなく、インストールしたアプリの互換性や安全性は保証しません。加固（パッカー）、ネイティブ SDK、ホットアップデートなどが問題を引き起こす可能性があります。問題が発生した場合は issue を提出してください。
- **同時に実行できる仮想アプリの数には制限がある**：スマートフォンのメモリとコンテナスロットの制約により、同時に実行できるコンテナプロセスは最大 16 個です。デフォルトでは自動管理され、メモリが逼迫すると最も長く使われていないバックグラウンドコンテナを終了します。

## 表記規則

- 本文書における「空间设置」（スペース設定）は、デスクトップ上のスペース設定アイコンを指します。
- 「应用管理」（アプリ管理）、「模型设置」（モデル設定）などは、いずれもスペース設定内のサブページです。
- NestSpace は AI 機能の検証を主目的とする実験的なプロジェクトです。インストールしたアプリの互換性や安全性は保証せず、同時実行数にも制限があります。詳細は[アーキテクチャと制限](architecture.md)を参照してください。
