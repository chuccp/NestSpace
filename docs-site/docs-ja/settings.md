# 設定の詳細

デスクトップの「空间设置」（スペース設定）にある各入口について説明します。一部のページにはより詳細な個別ドキュメントがあり、該当するセクションにリンクしています。

スペース設定は 2 階層です。ホームにはよく使う入口を置き、その下を「アプリとコンテナ」「アシスタント」「システムとネットワーク」に分類します。使用頻度の低い項目は 3 階層目にあります。プラグインセンターはスペース設定内ではなく、デスクトップの独立した入口です。

## プラグインセンター

プラグインセンターはソースプラグインとインストール済み `.nest` パッケージを管理します。内蔵モジュールは内部管理され、一覧には表示されません。プラグインをタップするとバージョン、提供元、Capability、詳細ページ、宣言型設定を確認できます。長押しすると有効化/無効化、設定、名前変更、共有、エクスポート、外部パッケージの削除ができます。

無効化すると Hook、ツール、Provider、設定、ランタイムプロファイルが現在のプロセスから直ちに削除され、インストール内容だけが保持されます。詳しくは[プラグイン作成ガイド](plugin-authoring.md)を参照してください。

## アプリとコンテナ

### アプリ管理

ホストにインストール済みのアプリと APK をインポートし、仮想アプリ、インスタンス、互換設定、インスタンスごとのデータを管理します。詳細は[アプリのインストールと管理](app-manager.md)を参照してください。

### ホスト制御（Root）

デバイスが root 済みで、NestSpace に su の使用が許可されている必要があります。

- 有効にすると、AI アシスタントと MCP に `host_*` ツールが追加され、仮想空間だけでなく実機全体の画面観察、タップ、入力、スクリーンショット、アプリ起動ができるようになります。
- 無効にすると、これらのツールはアシスタントと MCP のツール一覧からすぐに削除されます。
- 有効化のたびに su を再確認します。Root が利用できない場合はスイッチをオンにできません。
- 非常に強い権限です。信頼できる端末でのみ使用してください。

関連ツールは [MCP ツールリファレンス](mcp-tools.md) を参照してください。

### コンテナスロット

コンテナプロセスプールには最大 16 個のスロットがあり、各スロットは 1 つの独立したコンテナプロセスに対応します。

- **「自动」（自動）**（デフォルト）：メモリに応じて動的に管理し、最大で 16 個すべてのスロットを使用できます。メモリが逼迫すると、最も長く使われていないバックグラウンドコンテナが優先的に終了され、フォアグラウンドのコンテナは終了されません。
- **「固定档位」（固定スロット）**：同時に実行するコンテナプロセス数を制限します（1〜16）。上限を下げると、範囲を超えたプロセスが即座に終了されます。

変更はすぐに反映されます。プロセスを終了してもアプリデータは失われません。

### 座標シミュレーション

仮想空間内のアプリに緯度・経度をシミュレートします。

- 有効にすると、仮想アプリが `LocationManager` から取得する位置はページで設定した座標になります（既定の精度は 5 メートル）。
- 影響するのは仮想アプリのみで、実機の位置情報は変更されず、Root も不要です。
- アプリには引き続き位置情報の権限が必要です。実行中のアプリは、新しい座標を使用するために再起動が必要な場合があります。
- 独自の位置情報サービスを使うアプリ（一部の地図 SDK や Google Play 開発者サービスなど）は、実際の位置を返す場合があります。

### コンテナセルフチェック

一連の自動チェックを実行し、コンテナの基本機能が正常かどうかを確認します。

- 仮想アプリの起動。
- 画面の読み取りとスクリーンショット。
- 独立プロセス。
- WebView。
- MCP サービス。

各項目の結果は「合格」「一部合格」「失敗」「スキップ」に分類され、完全なレポートをコピーできます。互換性の問題を調査したり issue を報告したりする際に、セルフチェックレポートを添付すると役立ちます。

### ブラウザプロキシ

内蔵ブラウザ用に HTTP または SOCKS プロキシを設定します。

- すべてのタブとブラウザのダウンロードが同じプロキシを共用します。
- カンマ区切りのバイパスルールに対応しています。
- Android 10 以降かつ WebView が `PROXY_OVERRIDE` をサポートしている必要があります。
- ユーザー名／パスワードが必要なプロキシには現在対応していません。

詳細は[内蔵ブラウザ](browser.md)を参照してください。

## アシスタント

### モデル設定

AI アシスタントが使用するモデルインターフェースを設定します。Claude 互換と OpenAI 互換の 2 種類のプロトコルに対応しています。複数の設定を保存して切り替えることができ、各設定には次の項目が含まれます。

- プロトコル。
- 名前とプロトコルプリセット。
- Base URL。
- API Key。
- モデル名。
- コンテキスト Token の上限。
- 最大出力 Token。
- Temperature。
- 1 ラウンドあたりの最大ツール呼び出し回数。
- 思考レベル。
- ストリーミング出力。

API Key は Android Keystore で暗号化して保存され、どのツール結果にも平文で返されることはありません。一般的なプリセットは Base URL とモデル名を自動入力します。Claude 互換 URL にバージョンパスがない場合は `/v1/messages` が追加されます。プラグイン Provider は `plugin://<provider-id>` を使用し、API Key を空欄にできます。「测试连接」（接続テスト）をタップすると、実際のリクエストが 1 回送信されます。

詳細は [AI アシスタント](assistant.md) を参照してください。

### システムプロンプト

すべてのモデルが 1 つのシステムプロンプトを共用します。編集、保存ができ、内蔵のデフォルト値にワンタップで戻すこともできます。実行時には NestSpace が現在時刻、メモリ、スキルインデックス、ツールのルール、表示モードのルールを自動的に追加します。

### MCP ツール

**外部** MCP Server を設定し、ローカルの AI アシスタントがより多くのツールを使えるようにします。

- 複数の Streamable HTTP エンドポイントに対応。
- Bearer Token による認証。
- Token は Android Keystore で暗号化して保存。
- 更新後に `initialize` / `tools/list` をリクエスト。
- ツール名は `mcp_<サービス短 ID>_` プレフィックスを付けてローカルアシスタントに提供されます。

外部ツールはリモート MCP クライアントには公開されず、リモートクライアントから直接呼び出すこともできません。詳細は [MCP 制御サービス](mcp.md) を参照してください。

### メモリとスキル

![メモリとスキル](screenshots/memory-skills.jpg)

- **「记忆」（メモリ）**：アシスタントは各ラウンドの対話後に、事実、好み、手順を自動的に整理します。事実と好みはそのまま反映され、手順は標準／緩和権限ではそのまま反映されます。厳格モード、またはカスタムで「风险点击」（リスクのあるタップ）の確認を有効にしている場合は、先に確認カードが表示されます。ピン留め、承認、削除ができます。
- **「技能」（スキル）**：アプリに 7 個が組み込まれています。アシスタントは成功したマルチステップタスクからスキルを自動起草します。新しいスキルは常にデフォルトで無効になり、対話内に有効化カードが表示されます。使用のたびに成功／失敗が記録され、直近 3 回中 2 回失敗すると自動的に無効になります。手動で再度有効にするとカウントはリセットされます。
- カスタムスキルは編集、`SKILL.md` のインポート、バージョン履歴の表示、旧バージョンへの復元ができます。内蔵スキルは無効化のみ可能で、削除や上書きはできません。

メモリとスキルはアプリ専用ディレクトリに暗号化して保存されます。必要な場合、関連する項目はシステムプロンプトとともに現在設定されているモデルサービスへ送信され、ほかのサーバーにはアップロードされません。パスワード、認証コード、銀行カード、身分証明書の情報は自動的に記録されません。

### スケジュールタスク

アシスタントにスケジュールタスクを作成させます。例：「毎朝 9 時に天気を確認し、雨のときだけ教えて」。次の形式に対応しています。

- 1 回のみ。
- 毎日。
- 毎週。
- 固定間隔。

タスクは指定時刻になると元の対話内で実行され、結果の通知が送信されます。タスクはシステムのアラームでスケジュールされます。NestSpace がシステムによって完全に停止された場合、タスクのスケジュールは次回起動後に復元されます。

### 評価とリプレイ

実際のタスクで Agent をテストし、各実行のツール軌跡と結果を記録します。成功した後は、その流れをリプレイとして保存し、後から繰り返し実行できます。

### 子タスク記録

`spawn_agent` で作成されたサブ Agent を確認します。

- 状態と結果。
- 実行中の子タスクの停止。
- 結果は信頼できないデータとして扱われ、メイン Agent への参考情報としてのみ使用されます。

### トークン統計

リクエストごとに、モデルの入力 Token、出力 Token、思考 Token を確認できます。使用量とコストの見積もりに使用します。

### 権限レベル

アシスタントが機密性の高い操作を実行する前に確認を求めるかどうかを制御します。

| レベル | 動作 |
| --- | --- |
| 厳格 | インストール／アンインストール、権限の変更、リスクのあるタップ、ダウンロードなどすべてに確認が必要です。再利用可能な手順も先に確認を求めます |
| 標準 | 緩和に加えてアプリのインストール／アンインストールの確認が必要です。メモリと自動起草されたスキルはそのまま保存されます（スキルはデフォルトで無効） |
| 緩和 | 支払い、注文、送金、红包（お年玉）など、お金に関わる操作のみ確認を表示します |
| カスタム | 確認が必要なカテゴリを自分で選択します |

![権限レベル](screenshots/permissions.jpg)

確認できるカテゴリには、インストール、権限、ダウンロード、リスクのあるタップなどがあります。メモリとスキルの学習は機密性の高い操作には含まれません。再利用可能な手順が先に確認を求めるのは、厳格モードの場合、またはカスタムモードで「リスクのあるタップ」の確認が有効になっている場合だけです。自動起草されたスキルは常にデフォルトで無効で、対話カードまたはメモリとスキルのページで手動で有効にする必要があります。リモート MCP クライアントはこの設定の影響を受けません。リモートでのツール呼び出しはクライアント側で制御されます。

### フローティングドット

- フローティングドットのオン／オフ。
- ホスト画面とコンテナ内の色を設定。
- 透明度の調整。
- 音声の言語を選択。
- 位置の調整。
- オフライン音声モデルのダウンロード回線を切り替え、モデルをダウンロードまたは削除。

初めて有効にするときは「显示在其他应用上层」（他のアプリの上に表示）権限を付与する必要があります。フローティングドットは音声アシスタントへのショートカットです。詳細は [AI アシスタント](assistant.md) を参照してください。

### MCP 制御サービス

外部向けの MCP Server を起動／停止し、ローカルアドレスと LAN アドレス、Token、バックグラウンド起動に必要なオーバーレイ権限の状態を確認します。

詳細は [MCP 制御サービス](mcp.md) を参照してください。

### デスクトップ壁紙

- **English**。
