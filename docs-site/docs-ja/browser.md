# 内蔵ブラウザ

NestSpace には WebView ベースのマルチタブブラウザが内蔵されており、デスクトップに「浏览器」（ブラウザ）の入口があります。AI アシスタントと同じブラウザ機能を共有しており、アシスタントはバックグラウンドでタブを開き、ページを読み取り、タップし、ダウンロードできます。ユーザーはいつでも操作を引き継げます。

## ブラウザを開く

- デスクトップの「ブラウザ」。
- AI アシスタントが `browser_open` を呼び出して、表示可能なブラウザを開きます（`headless=false`）。
- アシスタントがデフォルトで開くのは**ヘッドレスタブ**で、表示可能なブラウザのタブバーで確認して引き継ぐことができます。

## タブ

- 複数タブに対応し、同時に最大 10 個まで保持できます。
- タブバーで切り替え、閉じる、新しいタブの作成ができます。
- 現在のタブを閉じると、隣接するタブが選択されます。
- ヘッドレスタブはアシスタントが作成し、表示可能なブラウザを開いた後に直接選択して引き継ぐことができ、ページの状態は失われません。
- すべてのタブは同じプロセスを共有しますが、それぞれ独立した WebView を持っています。

## アドレスバー

- 完全な URL を入力してウェブページを開きます。
- 通常のテキストを入力すると Bing で検索します。
- 戻る、進む、更新に対応しています。

## ヘッドレスモード

アシスタントが `browser_open` を呼び出すときはデフォルトで `headless=true` です。

- ページはバックグラウンドで読み込まれ、フォアグラウンドを占有しません。
- アシスタントは `tab_id` を使って複数のページを個別に読み取り、タップ、ナビゲートできます。
- ユーザーが認証コードやログインを処理する必要がある場合、アシスタントは `browser_hand_to_user` を呼び出してページを表示可能なブラウザに切り替えられます。

## ダウンロード

- ページから発生したダウンロードは、システムの **Download** ディレクトリに書き込まれます。
- Android 10 以降では MediaStore 経由で保存され、ファイル名、パス、サイズ、`content://` URI が返されます。
- ダウンロードした APK は「アプリ管理 → APK をインポート」で直接選択するか、`space_install_apk` に渡すことができます。
- アシスタントは `browser_download` で URL ダウンロードを開始し、`download_id` と `task_id` を即座に受け取ります。
- `task_wait` で `terminal=true` まで待機します。成功は `state=succeeded` のみで、タイムアウトしてもダウンロードはキャンセルされません。
- 必要に応じて `browser_download_status` でバイト数、進捗率、ファイル情報を取得できます。
- 各アシスタントセッションには現在のダウンロードが 1 つだけあります。置き換えるとそのセッションの以前のダウンロードがキャンセルされ、ユーザーや他のセッションのダウンロードは継続できます。

## アップロード

- ページのアップロードボタンをタップすると、システムのファイルピッカーが開きます。
- アシスタントは `browser_upload` を呼び出し、ローカルパスまたは `content://` URI で、現在待機中のファイル選択を完了できます。
- ユーザーが手動でファイルを選択することもできます。

## 認証コード、ログイン、ボット対策

ページに認証コード、人間確認、ログインウォール、ボット対策によるブロックが表示された場合：

- アシスタントは `needs_user` / `user_reason` / `challenge` の通知を検出します。
- `browser_hand_to_user` を呼び出してタブを表示可能なブラウザに切り替え、ユーザーに処理を委ねます。
- ユーザーが「完成」（完了）をタップすると、アシスタントは現在の URL、タイトル、本文、まだブロックされているかどうかを受け取ります。

アシスタントは認証コードやログイン制限を回避しようとはしません。

## プロキシ

入口：

- ブラウザ右上の歯車。
- 「空间设置」（スペース設定）→「浏览器代理」（ブラウザプロキシ）。

設定項目：

- 有効／無効。
- 種類（HTTP / SOCKS）。
- サーバーアドレス（ホスト名または IP のみを入力し、プロトコル、ポート、スラッシュは含めない）。
- ポート。
- プロキシをバイパスするアドレス（カンマ区切り、任意）。

説明：

- すべてのタブとブラウザのダウンロードが同じプロキシを共用します。
- Android 10 以降かつ WebView が `PROXY_OVERRIDE` をサポートしている必要があります。
- ユーザー名／パスワード認証が必要なプロキシには現在対応していません。
- アプリを再起動すると設定は自動的に復元されます。
- MCP ツール `nestspace_browser_proxy` でも設定できます。

## 制限

- ページは WebView 内で動作するため、システムブラウザと同じではありません。一部のサイトは WebView を検出したり、機能を制限したりします。
- ログイン状態は WebView の Cookie に依存しており、NestSpace のデータを消去すると一緒に消去されます。
- ボット対策、認証コード、ログインはユーザーが処理する必要があり、アシスタントは引き継ぎのみを行います。
- プロキシは平文での転送であり、TLS 終端は行いません。
