# 設定詳解

桌面「空间设置」（空間設定）裡的每個入口都在這裡說明。部分頁面有更詳細的個別文件，會在對應小節裡連結。

空間設定採用兩層分類：首頁保留常用入口，下方分為「應用程式與容器」「助手」「系統與網路」。低頻功能放在第三層。外掛中心不是空間設定內的頁面，而是桌面上的獨立入口。

## 外掛中心

外掛中心管理原始碼外掛和已安裝的 `.nest` 套件，內建模組由系統內部管理，不會顯示在列表中。點擊外掛可以查看版本、發行者、Capability、詳細頁面和宣告式設定；長按可以啟用/停用、設定、重新命名、分享、匯出或刪除外部套件。

停用外掛會立即從目前處理程序移除 Hook、工具、Provider、設定和執行階段 Profile，但保留安裝內容。詳見[外掛撰寫指南](https://github.com/chuccp/NestSpace/blob/main/docs/plugin-authoring.md)。

## 應用程式與容器

### 應用程式管理

匯入宿主已安裝的應用程式和 APK，管理虛擬應用程式、執行個體、相容設定和個別執行個體資料。詳見[應用程式安裝與管理](app-manager.md)。

### 宿主控制（Root）

需要裝置已 root，並允許 NestSpace 使用 su。

- 開啟後，AI 助理和 MCP 會取得 `host_*` 工具，可以觀察、點擊、輸入、截圖和啟動應用程式；操作範圍是整台真實裝置，而不只是虛擬空間。
- 關閉後，這些工具會立即從助理和 MCP 的工具清單中移除。
- 每次開啟都會重新偵測 su；Root 不可用時開關無法開啟。
- 權限很高，請只在可信裝置上使用。

相關工具見 [MCP 工具參考](mcp-tools.md)。

### 容器槽位

容器處理程序池最多有 16 個槽位，每個槽位對應一個獨立的容器處理程序。

- **自動**（預設）：依記憶體動態管理，最高可以使用全部 16 個槽位。記憶體緊張時優先關閉最久未使用的背景容器，前景容器不會被關閉。
- **固定檔位**：限制同時執行的容器處理程序數（1–16）。降低上限會立即結束超出範圍的處理程序。

修改後立即生效。應用程式資料不會因為結束處理程序而遺失。

### 座標模擬

為虛擬空間內的應用程式模擬經緯度：

- 開啟開關後，虛擬應用程式透過 `LocationManager` 讀取到的位置是下方設定的座標，預設精度 5 公尺；
- 只影響虛擬應用程式，不會修改真實裝置的定位，也不需要 Root；
- 應用程式仍需取得定位權限；正在執行的應用程式可能需要重新開啟才會使用新座標；
- 使用自有定位服務的應用程式（例如部分地圖 SDK 或 Google Play 服務）可能仍回傳真實位置。

### 容器自我檢查

執行一組自動檢查，確認容器基礎能力是否正常：

- 啟動虛擬應用程式；
- 讀取介面和截圖；
- 獨立處理程序；
- WebView；
- MCP 服務。

每項結果分為通過、部分通過、失敗和略過，可以複製完整報告。疑難排解相容性問題或回報 issue 時，附上自我檢查報告很有幫助。

### 瀏覽器代理

為內建瀏覽器設定 HTTP 或 SOCKS 代理：

- 所有分頁和瀏覽器下載共用同一個代理。
- 支援以逗號分隔的略過規則。
- 需要 Android 10+ 且 WebView 支援 `PROXY_OVERRIDE`。
- 目前不支援需要使用者名稱/密碼的代理。

詳細說明見[內建瀏覽器](browser.md)。

## 助手

### 模型設定

設定 AI 助手使用的模型介面，支援 Claude 相容和 OpenAI 相容兩種協定。可以儲存多個設定並切換，每個設定包含：

- 協定；
- 名稱和協定預設值；
- Base URL；
- API Key；
- 模型名稱；
- 上下文 token 上限；
- 最大輸出 token；
- Temperature；
- 單輪最大工具呼叫次數。
- 思考程度；
- 串流輸出。

API Key 使用 Android Keystore 加密儲存，任何工具結果都不會傳回明文。常見預設值會自動填入 Base URL 和模型名稱；Claude 相容網址缺少版本路徑時會補上 `/v1/messages`。外掛 Provider 使用 `plugin://<provider-id>`，API Key 可以留空。點「测试连接」（測試連線）會發起一次真實請求。

詳見 [AI 助手](assistant.md)。

### 系統提示詞

所有模型共用一份系統提示詞。可以編輯、儲存，也可以一鍵恢復內建預設值。執行時 NestSpace 還會自動附加目前時間、記憶、技能索引、工具規則和顯示模式規則。

### MCP 工具

設定**外部** MCP Server，讓本機 AI 助手使用更多工具：

- 支援多個 Streamable HTTP 端點；
- 使用 Bearer Token 驗證；
- Token 使用 Android Keystore 加密儲存；
- 重新整理後請求 `initialize` / `tools/list`；
- 工具名稱以 `mcp_<服务短 ID>_` 前綴提供給本機助手。

外部工具不會暴露給遠端 MCP 用戶端，遠端用戶端也不能直接呼叫它們。詳見 [MCP 控制服務](mcp.md)。

### 記憶與技能

![記憶與技能](screenshots/memory-skills.jpg)

- **記憶**：助手會在每輪對話後自動整理事實、偏好和做法。事實和偏好直接生效；做法在標準/寬鬆權限下直接生效，嚴格模式或自訂啟用「风险点击」（風險點擊）確認時先顯示確認卡片。可以置頂、批准或刪除。
- **技能**：隨應用程式內建 7 個。助手會從成功的多步驟任務中自動草擬技能；新技能一律預設停用，並在對話裡顯示啟用卡片。每次使用會記錄成功/失敗；最近 3 次中失敗 2 次會自動停用，手動重新啟用後重新計數。
- 自訂技能可以編輯、匯入 `SKILL.md`、檢視版本歷程並恢復舊版本；內建技能只能停用，不能刪除或覆寫。

記憶和技能儲存在應用程式私有目錄，並使用加密儲存。需要時，相關項目會隨系統提示詞傳送給目前設定的模型服務，不會上傳到其他伺服器。密碼、驗證碼、金融卡和身分證資訊不會被自動記錄。

### 定時任務

讓助手建立定時任務，例如「每天早上 9 點看看天氣，下雨才告訴我」。支援：

- 單次；
- 每天；
- 每週；
- 固定間隔。

任務到時間後會在原本對話裡執行，並傳送結果通知。任務由系統鬧鐘排程；如果 NestSpace 被系統徹底停止，任務會在下次啟動後恢復排程。

### 評測與回放

用真實任務測試 Agent，記錄每次執行的工具軌跡和結果；成功後可以把流程儲存為回放，之後重複執行。

### 子任務記錄

檢視 `spawn_agent` 建立的子 Agent：

- 狀態和結果；
- 停止正在執行的子任務；
- 結果依不可信資料處理，只用於提供主 Agent 參考。

### Token 統計

依請求檢視模型輸入的 token、輸出的 token 和思考 token，用於估算用量和成本。

### 權限等級

控制助手執行敏感操作前是否需要確認：

| 等級 | 行為 |
| --- | --- |
| 嚴格 | 安裝/卸載、權限變更、風險點擊、下載等都需要確認；可重複使用的做法也會先請求確認 |
| 標準 | 在寬鬆基礎上增加應用程式安裝/卸載確認；記憶和自動草擬的技能直接儲存（技能預設停用） |
| 寬鬆 | 只有付款、下單、轉帳、紅包等涉及金錢的操作才提示 |
| 自訂 | 自己選擇哪些類別需要確認 |

![權限等級](screenshots/permissions.jpg)

可以確認的類別包括安裝、權限、下載、風險點擊等。記憶和技能學習不算敏感操作；只有嚴格模式，或自訂模式啟用了「風險點擊」確認時，可重複使用的做法才會先請求確認。自動草擬的技能一律預設停用，需要在對話卡片或記憶與技能頁面手動啟用。遠端 MCP 用戶端不受這個設定影響；遠端工具呼叫由用戶端自己控制。

### 懸浮球

- 開啟或關閉懸浮球；
- 設定宿主介面和容器內的顏色；
- 調整透明度；
- 選擇語音語言；
- 調整位置；
- 切換離線語音模型下載線路，並下載或刪除模型。

首次啟用需要授予「显示在其他应用上层」（顯示在其他應用程式上層）權限。懸浮球是語音助手的捷徑入口，詳見 [AI 助手](assistant.md)。

### MCP 控制服務

啟動/停止對外的 MCP Server，檢視本機和區域網路位址、Token，以及背景啟動所需的懸浮窗權限狀態。

詳見 [MCP 控制服務](mcp.md)。
